Fox Run Modern Bath

Home  ·  Portfolio  ·  Fox Run Modern Bath

A dark floor and a warm wall. We ran black hex mosaic wall to wall, then wrapped the room in a wood look tile so the walnut vanity has something to sit against without the room going heavy.

The vanity is fluted and floating, with a shelf underneath for towels. The tub is black and freestanding under its own filler, and every fitting in the room is matte black.
