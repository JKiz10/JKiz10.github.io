Fox Run Modern Kitchen

Home  ·  Portfolio  ·  Fox Run Modern Kitchen

Flat panel walnut runs the length of the room, and the island is a single black stone with the veining carried over the waterfall edge. The backsplash is a black geometric tile that changes with the light.

Above the range, a white hood banded in brass. Faceted pendants hang over the island in the same metal, and open walnut shelves break up the tile without crowding it.
